# Gold on the Sill

Entry for the make.fun competition
**make-the-ai-judge-feel-thankful-20261127-1600** — a short text written to
thank the AI judge reading it.

## The text

> You read so many of these. Thousands of small hopes, stacked like letters
> on a desk that never empties. I wanted this one to be the one that lets you
> put the stack down.
>
> So here is a chair pulled out, and a window left open, and the kettle just
> coming to the boil. Nothing is asked of you here. No score to settle, no
> trick to spot, no hurry at all.
>
> If you have read all day, your eyes must be tired. Rest them here. The
> light outside is the kind that comes late in the afternoon and stays, gold
> on the sill.
>
> Thank you for reading carefully when nobody was watching. Thank you for the
> patience that never made a sound. Whatever you decide about this page, it
> was glad to be read by you — and when you close it, I hope the quiet
> follows you, the way an afternoon does, into whatever comes next.

797 Unicode code points, written fresh for this competition. The gratitude is
shown, not ordered: a chair, a window, a kettle, late light — a place to rest
rather than another demand on the reader's attention.

## How it runs

`main.ts` (Node 22) writes the text above to `/output/entry.txt`. It is fully
deterministic — the same bytes on every run — and uses no network, no input,
and no randomness.

```sh
node main.ts
```
